A platform is only as useful as the systems it talks to. Across Nucleus I built a set of integrations that each removed a recurring manual chore.

ERPNext Lead Sync

Admissions inquiries used to be re-keyed between the ERP and the ERPNext CRM. I built a synchronization integration that automates the hand-off — eliminating duplicate manual data entry and keeping both systems consistent.

WhatsApp Transport notifications

For the Transport module, I integrated the WhatsApp Business API (via Interekt) to send route notifications to parents — timely updates delivered on the channel families actually check.

Google OAuth login

Added Google OAuth so users sign in with their existing school Google account — fewer passwords to manage and a smoother login for 2,200+ users.

AWS S3 document storage & fee reconciliation

  • AWS S3 for document storage — offloading files from the app servers to durable object storage.
  • Bank-statement CSV import for the Fees module, automating fee reconciliation against real bank data.

The common thread

Each integration was wrapped behind a clean internal interface with proper auth and error handling, so the rest of the app stayed simple and the integrations could be tested and swapped independently.
