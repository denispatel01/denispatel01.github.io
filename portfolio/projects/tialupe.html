TiaLupe — Children's Hospital LA App API

Web API endpoints powering a doctor-appointment booking app serving thousands of patient-facing users.

ASP.NET Web API SQL Server Healthcare

▶ Try the live demo

TiaLupe is a mobile app deployed for Children's Hospital Los Angeles. I built and maintained the Web API endpoints behind it — the layer that lets thousands of families book and manage doctor appointments.

What I worked on

  • Designed and maintained Web API endpoints powering appointment booking for a patient-facing mobile app.
  • Kept the API reliable at the scale of thousands of users in a healthcare context, where correctness and uptime matter.
  • Deployed and supported the application across four environments (Dev / Staging / UAT / Production).

Context

This was early in my career at an ISO 27001:2013-certified agency. Working on a healthcare product for a major children's hospital taught me the discipline of building APIs that other teams — and real patients — depend on.
